# ScanSci SVG library

These SVG source files are imported from [Rimagination/scansci-svg](https://github.com/Rimagination/scansci-svg), `skill/assets/library/`.
The repository documents the library as CC BY 4.0. The original attribution is
kept in each Rylume manifest through `author`, `source_url`, `license`, and
`license_url` fields. Rylume only sanitises the SVG element/attribute set for
safe local editing; it does not claim authorship of these source drawings.
