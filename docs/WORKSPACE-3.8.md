# Rylume 3.8 · 左侧图版导航与顶部绘图工具

这一版根据核心交互反馈，彻底重构了工作区结构：最近生成的图版常驻左侧栏，绘图工具集中在正上方，首页采用类似主流 AI Harness 的直接输入体验。

## 交互设计依据

| 模块 | 3.7 及之前的问题 | 3.8 改进方案 |
|---|---|---|
| **图版导航** | 最近图版藏在历史任务对话框中，切图和找图不便 | 左侧常驻固定导航栏，按日期（今天/昨天/更早）分组，支持实时搜索与当前文档高亮；支持一键折叠为 56px 紧凑图标栏 |
| **工具排布** | 工具散落于左侧竖轨、浮动工具栏和右属性栏，容易遮挡画面 | 绘图工具统一排布在顶部工具栏；选区快捷编辑固定在工具栏正下方属性行，绝不遮挡画布 |
| **首页体验** | 首页先展示三个大卡片，必须点击后才弹出创作窗口 | 首页直接呈现主输入框（“今天想画什么？”），参考图与草稿按需展开，搭配底部轻量快捷入口 |
| **草稿保护** | 临时切去看旧图版容易丢失刚才写了一半的新图想法 | 新建图版的描述词、优化候选与参考附件在切换文档时自动隔离保护，切回后完整还原 |
| **模式切换** | 极简与专业模式工具位置跳动 | 极简模式仅保留核心操作与顶部静态属性行，专业模式按需展开图层与属性抽屉，排布稳定一致 |

## 核心功能说明

1. **左侧常驻图版导航（App Sidebar）**
   - 顶部品牌与「+ 新建图版」主操作。
   - 实时搜索过滤框，支持图版标题与分类检索。
   - 按日期分组展示最近图版，并标注生成中、草稿或未完成状态。
   - 支持通过汉堡按钮折叠为 56px 极简侧栏，记忆折叠偏好；折叠后顶部提供展开入口。

2. **顶部绘图工具栏（Top Tools）**
   - 集中提供：选择、平移、添加连线、添加文字、模板库、添加素材、AI 生成、批注修改等工具。
   - 选中对象时，下方直接展开静态属性行（文字修改、字号、颜色、复制、删除、对齐），无需打开右侧繁琐面板即可完成常用编辑。
   - 素材抽屉与图层面板作为按需抽屉打开，不会挤占或覆盖工作区。

3. **主流 Harness 风格首页（Home Composer）**
   - 宽屏居中主输入框，支持直接输入科研场景或提示词。
   - 点击「+ 参考 / 草稿」即时在卡片内展开参考图上传、手绘草稿与排版策略选项。
   - 底部提供「从模板开始」「打开空白画布」「试着编辑示例图」三个一键启动入口。
   - 支持 Ctrl+Enter 快捷提交。
