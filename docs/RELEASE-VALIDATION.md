# 3.0.0 发布核验

核验对象是独立的发布源码与重新构建的 Windows x64 程序；使用隔离的空数据目录，未调用付费模型接口。

- Python 3.13.3、PyMuPDF 1.28.2 / MuPDF 1.28.2：388 项测试通过，1 项交互式原生窗口测试在普通套件中跳过。
- 9 个前端行为脚本全部通过，覆盖选择、连接、撤销、草稿恢复、批注对比与素材检索。
- 最终打包程序：样板建立、层级调整、独立导入、重命名、分类、归档、版本恢复及退出重启一致性通过。
- 同一修订的 SVG / PDF / PNG / PPTX 导出通过；样板 PPTX 无栅格媒体，包含原生形状。
- 原生 WebView 窗口冒烟单独通过，退出码为 0。
- PyMuPDF 动态库与官方 1.28.2 Windows wheel 哈希一致；对应的 MuPDF 1.28.2 源码包含在发布依赖源码包中。
- 清理源码、分发目录和解压后的 PyInstaller 模块未检出开发者本机密钥或常见凭据格式。最终 ZIP 与 Git 版本另行核对。

本记录描述已执行的本地核验；在线 AI 服务可用性与具体论文中的科学机制需要使用者按自己的配置和研究情境确认。
