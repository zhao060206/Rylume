# 导入图的主画布内部元素编辑

顶部「内部元素」开启路径选择。点击路径后可以直接拖动，Shift 点击多选；「框选图标」允许从有颜色的区域开始框选，完整包含的路径加入选区，大背景不会加入小范围选区。多条路径可以一起移动。完成后回到常规画布模式，文字可双击修改，也可选中后移动。

- 移动按照父级变换的逆矩阵换算，适用于缩放和旋转的导入对象。
- 拖动过程中仅更新所选路径，释放鼠标按最终位置提交一次修改。取消、失焦或拖动中撤销会恢复临时变换。
- 每次只提交涉及的素材快照，使用原有修订、自动保存和撤销流程。保存确认后保留选区，切换文档退出内部元素模式。
- 方向键微调 0.1 mm，Shift + 方向键微调 1 mm；可改色和删除。无填充的轮廓箭头改变描边颜色，保持无填充。
- 矢量细节工作区继续用于聚焦编辑；未选中的路径和对象保持原位。

导入图标可能由多条路径组成，需要框选或多选；这里没有宣称自动识别所有图标的语义分组。导入箭头仍是可编辑轮廓，新建的原生连接线才具有端点绑定和吸附。没有以位图覆盖或降低导入精度代替可编辑路径。
