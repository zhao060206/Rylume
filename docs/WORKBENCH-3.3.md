# 第一张图：Rylume 3.3

3.2 减少了常驻控件，但把部分高频操作藏得太深，也没有解决新建后的空白状态。这次按第一次使用者完成一张图的顺序调整界面。

## 不需要先配置 AI

首页「先试着改一张图」直接创建独立的可编辑示例；已有图版保留。需要自己画时选择「自己画一张」，素材库自动展开。也可以浏览模板，查看实际图版后使用。

只有 AI 生成功能需要自己的模型服务。模板、添加素材、手动编辑和导出可以直接使用。

## 点选、拖动、改字

1. 点一下左侧素材，将它加入纸张。新增对象会保持在视野内。
2. 拖动图形调整位置；双击图形或点击下方「修改文字」开始输入。
3. 点「完成」保存文字，点「取消」保留原文；在上方文字框中修改也可以。
4. 复制、删除和排列直接显示在所选对象旁。误删或移动错了，可以点有文字标记的「撤销」。

素材搜索没有结果时可一键清空搜索与筛选，保留所选学科。素材列表自己滚动，搜索和分类保留在面板顶部。小窗口插入对象后收起素材抽屉，给编辑留出空间。

## 连线

有两个图形后，点击「添加连线」。选中了一个图形时，它自动作为起点；否则先点起点，再点终点。界面会写出当前起点，提供取消操作。

常用的激活、抑制和流程顺序显示符号与文字；结合、转换、转运等在完整含义说明中选择。连好后自动选中这条线，可以确认含义、补充线上文字或删除。移动图形后连线仍绑定原对象。

连接类型由作者选择；软件不把流程箭头自动当成科学激活。已有证据核对标记仍保留。

## 保存与导出

图版编辑会自动保存在软件里。需要给论文、同事或 PowerPoint 使用时，点击「导出图片」：

- 用于论文或汇报：PNG，默认 300 DPI，可选 600 DPI。
- 放进 PowerPoint 继续编辑：PPTX，按对象能力保留可编辑图形与文字；位图会明确说明。
- 投稿或打印：PDF，保留物理尺寸。
- 在其他绘图软件里编辑：SVG。

保存完成后显示文件位置，并可打开保存文件夹。导出失败或取消时，原图版仍然保留。排版检查可定位到图上、预览后应用，也可继续编辑和导出；科学内容仍由作者核对。
