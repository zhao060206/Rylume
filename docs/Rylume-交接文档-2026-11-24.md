## 1. 项目是什么

理象 Rylume 是一款面向科研人员的 Windows 本地绘图软件，用来做科研示意图、机制图和实验流程图。

- 用户可以从研究描述、手绘草图、模板、空白画布或已有的科研图开始。
- 图形、文字和连线存在同一份场景文档里，在画布上可以分别编辑。移动对象时，绑定的连线会跟着走。
- 图版按项目归档，保留保存修订。可以导出 SVG、PDF、PNG 和 PowerPoint。能编辑到什么程度，取决于图版里有没有位图或保留原字形的轮廓。
- 技术栈：后端是 Python；前端是 HTML、CSS、JavaScript 和 SVG；桌面界面由 WebView2 承载。
- 内置模板、素材和手动编辑可以离线用。AI 起稿、批注修改和视觉审阅用的是用户自己配置的模型服务。
- 其他功能：双语素材库、个人素材和模板、科研图转换，以及把文档转成 Markdown 后提取绘图建议。

## 6. 为什么用户觉得“和之前没多大区别”

用户对这一轮的原话是：**“和之前没多大区别，还是不太正常。”** 已经查到的原因：

1. **之前看的预览不是真实界面。** 首页很多样式要靠脚本加的状态类才生效。静态预览去掉了脚本，所以截图里这些都没出现：
   - `.view-home`：`workspace.css` 已经用它在首页隐藏“极简/专业”切换和“导出”，并去掉顶栏的下边框。
   - 画布区域的 `showing-start`：起始页靠它铺满。
   - `home-composer-host`：“用 AI 起稿”的输入框是 `ui/creation-composer.js` 在运行时填进去的。
2. **在较窄的窗口里，新样式可能没生效（还没确认）。** `shell.css` 有很多规则写在宽度大于 981px 或 1051px 的媒体查询里，比这窄的时候还是旧样式在控制。需要逐条核对每条规则在什么宽度下起作用。
3. **这几轮只换了颜色、边框和细节，布局本身没动。**
4. **还有旧样式残留：**
   - 首页输入框 `.home-inline`（在 `ui/creation-composer.css`）还是旧的绿灰色 `#cfd8d2` / `#769287`，圆角 16px。
   - 侧栏品牌名用的是衬线字体，来自 `ui/styles/workspace.css` 第 13 行：`font:500 14px Georgia,serif`。

所以下一步不能再一处处小修，要改的是布局本身。
