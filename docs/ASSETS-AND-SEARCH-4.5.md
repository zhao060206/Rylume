## 来源与转换

素材来自 [Bioicons](https://github.com/duerrsimon/bioicons/tree/d29e766ea7580b8063c4f47b29e872db40a4d979/static/icons)，固定版本为 `d29e766ea7580b8063c4f47b29e872db40a4d979`。已联网核对上游 README、目录与许可，并将每个新增原文件的 Git blob 摘要和公开树记录核对。缓存的完整上游归档不随软件分发。

每项保留作者、独立 CC0 / CC BY 3.0 / CC BY 4.0 许可、原始 SVG、SHA-256、固定来源 URL 和修改说明。原文件按字节保存，Git 不转换其换行；署名仍随导出产生。记录见 [manifest](../assets/bioicons/manifest.json) 和 [完整署名](../assets/bioicons/ATTRIBUTION.md)。

本机导入工具将绘图元素展开为可编辑路径，保留描边变换、圆端点、透明度和填充规则。拒绝脚本、外部引用、嵌入位图、无法展开的文字及不支持的效果；按路径去除重复图形。用能处理裁剪的 CairoSVG 对照原图与转换图，要求去除画布留白后平均亮度差不高于 3.5%，深色细节及轮廓召回均不低于 94%。这两项是外观筛查指标，不代表科学内容得到独立验证。

抽查了各分类原图与矢量的并排预览。测试额外覆盖改变画面的裁剪不能蒙混通过、毫米单位与变换不能使轮廓变细、带透明度与圆端点的图形仍保持外观。四格式导出测试确认新增素材保留矢量结构、独立对象与署名，PPTX 主体不含图片。

复现导入可使用 `tools/import_scientific_art.py` 和 `tools/scientific_asset_terms.json`；导入只读取指定归档，不执行下载内容，不调用模型。CairoSVG 属于开发期验证依赖，桌面应用无需它。

## 搜索行为

- 中文、英文名称、关键词、常用缩写、部分常用拼音别名可以互查，例如 `线粒体`、`mitochondria`、`xlt`。
- 中文近似字与英文拼写偏差可匹配，例如 `线粒题`、`microsocpe`、`erlenmayer`；近似项明确标注，保留真实名称供作者核对。
- 多个词必须共同匹配，例如 `线粒体 剖面`。分类、学科、风格、收藏、最近使用等筛选继续生效。
- CD4/CD45、IL-6/IL-8 等编号名称不会相互纠错，短科学缩写也不作字形替换。搜索不改变标签、对象身份或素材许可。
- 准确名称与同义词优先于近似词；本机缓存索引，连续输入延迟 100 ms 后更新结果，中文输入法组合过程中保持稳定。
- 「我的素材」使用同一匹配规则；搜索可核对名称与分类，不改变归档和确认状态。

实际浏览器验证了中文错字、英文错拼、跨学科、组合词、近似标记及点击结果插入可编辑对象；页面无控制台错误。真实目录基准查询约 7–41 ms，数值与机器及词条有关。新增自动化场景检查同义词、拼音、相邻字母颠倒、多个词共同匹配、编号保护、筛选、空结果与可变名称缓存。

本轮使用独立数据目录测试，不替换用户本机安装或桌面快捷方式。发布包和更新日志另行生成。

自动化验收：585 项 Python 测试及 7 项子测试通过，原生窗口测试单独运行；29 组 JavaScript 测试通过。目录断言按实际学科与包来源核对，已适配新增内置素材与可选下载包并存的情况。
