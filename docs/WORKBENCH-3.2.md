# Rylume 3.2 工作台

这次重设计集中解决常驻控件重复、左右面板挤占画布、选取对象后出现多层工具栏的问题。

## 信息架构

- 顶部：品牌、文件／编辑／视图／设置、图版名称和保存状态、最近图版、导出。
- 左侧：生成、模板、素材、参考、图层。同一按钮再次点击即收起，每个展开的面板也有关闭按钮。
- 绘图工具：撤销、重做、选择、平移、连线、文字；右侧提供属性、批注、检查。
- 快捷编辑：仅在选中对象时出现文字、字号和颜色；层级、复制、删除、组合、对齐和图例收进「更多」。打开属性栏后不重复显示快捷字段。
- 连线：进入连接工具或选中连线时，才显示带符号预览的关系类型。完整含义说明和导出图例仍可使用。
- 底部：画布尺寸与缩放。吸附、网格和缩放预设进入「视图」。

生成面板以研究描述为主，参考图、引导、输出设置、样板分别按需展开。素材保留学科和分类，风格、收藏与最近使用收进筛选。批注与其他侧栏切换时互斥，避免覆盖叠加。

默认收起左右面板。开关面板时保持画布中心与缩放；改字或选择对象不会改变画布可用高度。保留所有既有场景、直接编辑、AI 候选、检查、资源下载和软件更新功能。新界面主题位于 `ui/canvas-workbench.css`，旧入口 `/legacy` 使用原有主题。

## 视觉规则

采用白色工具面、暖灰画布、深灰文字和克制的绿色选中态。主动作只有导出及当前面板的提交操作。常用工具保留中文文字；较小窗口才缩为带说明的图标。使用本机系统字体，无需下载网页字体。不使用渐变、发光、装饰性指标或多层卡片。

应用界面和科学图形分开：界面主题不会更改论文图中的颜色、文字或对象位置。

## 实际查阅的官方参考

2026-10-30 查阅以下资料，仅学习信息层级与操作原则，未复制产品素材、图标或界面代码：

1. [Sketch：The Mac app interface](https://www.sketch.com/docs/interface-and-settings/the-mac-app-interface/)：工具栏根据当前操作提供上下文选项，检查器对应选中图层；画布和图层导航各有明确职责。
2. [Linear：How we redesigned the Linear UI, part II](https://linear.app/now/how-we-redesigned-the-linear-ui)：减少视觉噪声、统一导航和标题对齐，以少量基础变量组织表面、文字和层级，并在不同环境下验证。
3. [tldraw：官方产品与功能说明](https://tldraw.dev/features)：选择与变换、画布导航、布局和组合是一组基础编辑能力，界面应服务于这些高频动作。

本地 ui-ux-pro-max 的极简主义样式建议与方向相符；其生成的营销页结构、深色紫色配色和网页滚动动效不适用于本产品，因此未采用。

## 验证

自动化验证画布重排前后中心坐标和缩放不变、面板展开状态与辅助属性一致。浏览器验证实际样板的创建、改字、保存、撤销、关系说明、素材搜索、批注、检查、模板预览、导出以及设置菜单。AI 生成与批注修改仍使用现有服务，本次界面验证不消耗用户的模型额度。
