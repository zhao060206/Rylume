# 连线吸附与批注重绘

在连线工具下，从对象边缘拖向另一对象，或依次点击起点与终点。靠近上下左右中点时自动吸附；矩形流程框另有四角。提示大小和吸附距离按屏幕像素计算，缩放后手感一致。按住 Alt 可选择任意边缘位置。已选连线的起终点也支持相同操作。端点按对象的相对边缘位置保存，移动、旋转和缩放对象时跟随；提示标记不保存、不导出。

未确认的连线通过顶部“连线待核对”入口集中处理。定位后核对类型、方向与说明，明确点击“保存定义”才清除待核对状态。仅更换符号不代表科学证据已核对。自动问号从画布和导出移除，作者自行写入的文字保留。

批注默认使用对象编辑。原始要求明确重绘插画，或对现有插画明确提出写实纹理等需求时，可以调用用户配置的生图服务；“更高级”“更美观”等含糊要求先列明对象，询问后创建新候选。每条批注也可设置不调用生图。禁止生图、只改字等原始限制优先于允许选项；AI 优化表达不能授予新的调用权限。

重绘使用当前对象实际图像作为参考，只替换主体插画。对象身份、位置、独立标签、连线和未涉及对象受结构校验保护。每次最多 8 个主体，每个主体至多两次图像请求（第二次仅用于纠正重复主体）；核验重试复用已返回的图片，不反复生图。服务可能计费。

候选和核验逐批注记录。未配置视觉模型时，只能自动检查结构与文字；已重绘的插画必须由作者在对比窗口确认。作者确认不能绕过未满足要求、范围错误、版本冲突或图像授权检查。应用前原图保持不变；应用和恢复均保存新修订，历史保留。

验证采用本机模拟兼容模型服务和合成图片，未使用或打包私人密钥。自动测试证明流程约束，真实图像的科研正确性与美观度仍需作者审图。
