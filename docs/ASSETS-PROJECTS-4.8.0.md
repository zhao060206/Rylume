# 素材与项目管理验收

4.8.0 对整个内置目录和七个学科资源包进行图片身份与双语字段检查。来源名称未识别、翻译不完整或旧图片映射不可靠时，素材标记为 `quarantined`，不进入选择、搜索和模型候选。其原始 ID 和文件继续支持旧图稿与快照，避免静默改变作者已经保存的图。

本次目录包含 936 条来源名称已对应的内置外部素材，以及七个资源包中的 470 条可用素材记录。内置尚需核对译名或图形含义的 752 条、旧版按哈希或宽泛别名映射的 729 条学科素材已隔离；另有 2 条新增润湿性示意因接触角表达含糊而隔离。数量不是独立图片数，部分器材与器官按学科重复提供。完整条目及待确认词见 `assets/asset-catalog-audit.json`，逐素材映射见 `assets/asset-catalog-review.json`。

图源核对依据是固定版本的原始图片文件名、来源、明确的双语名称和文件校验。它不等于每个符号的科学用途均已人工认证；科研图仍需作者确认。没有来源名称映射的导入请求直接失败，不会选择相似图片充数。

本轮另逐页查看了 23 张联系表，覆盖当时全部 1410 条可选记录的图形与标签；随后隔离 4 条有歧义的记录，保留 1406 条。修正离心管品牌 Falcon 被译成鸟类、放射性标记被译成无线电、终端被译成神经末梢、米饭被译成水稻、磁体形状与标签不符等问题；解剖视角和仪器名称使用完整短语。具体图形更正与隔离原因记录在 `assets/asset-visual-review.json`，专业短语记录在 `assets/asset-name-phrases-zh.json`。联系表用于发现明显错配，并非所有科学细节的领域专家认证。

## 必须通过的实际操作

- 搜索分析天平，缩略图与插入对象均使用 Servier 的 `scale.svg`；保存后的素材快照保留同一来源。
- 心肌细胞、红细胞、紧密连接和空白细胞在中文与 English 模式下显示独立名称；分类、筛选和详情同步变化。切换、刷新、再次打开后保留语言偏好，图上已有文字不被更改。
- 新建空项目，无图版时仍可见；新建画布、从模板创建或 AI 新任务会归入提交时选定的项目。修订任务继承原任务项目。
- 移动图版、项目改名、跨项目拖动和项目内排序可写入本机；重新打开软件后项目 ID、归属和顺序不变。
- 移除项目将图版转入“未归入项目”，不删除场景、导出文件或历史修订。
- 旧自由文本分类自动迁移为项目，只迁移一次；改名或移除后不会从旧分类重新生成旧项目。

项目目录独立保存在数据目录的 `projects.json`。移动与排序不会创建无关的场景修订；读写使用原子替换。Windows 短暂文件占用会有界重试，持续失败保留原文件与待写入文件。
