# AI 绘图专项检查与修复记录 · 3.6.2

检查范围是从描述、参考图和草稿到生成、编辑、重绘、重试、恢复和导出的实际流程。本轮先补可失败的复现，再修复；模型运输层替身用于可重复异常测试，真实模型成图另行核对。两类证据分别记录。

## 已确认并修复的问题

| 问题 | 修复后的行为 | 验证方式 |
|---|---|---|
| 后台生成使用被手动编辑更新的修订号，覆盖作者已经保存的改动 | 生成固定自己的基础修订，发生竞争时停止后台写入，保留作者编辑 | HTTP 测试在模型调用中途保存位置与文字，再释放模型响应 |
| 数量相同就按列表顺序猜对象身份 | 优先稳定 ID、唯一名称和完整分期；匹配不明保留原对象并给待核对项 | 调换顺序、无关主体、同名对象测试 |
| 草稿里的锁定对象、独立文字及样式被规划器改掉 | 保留作者锁定主体、文字、位置、偏移、颜色和字号 | 对抗草稿测试、真实插画中保留锁定备注 |
| 零连线参考草稿被补上激活箭头，遗漏主体时丢对象 | 严格草稿只采用观察到的连接；缺少的观察主体保留，不能自动发明因果关系 | 无箭头手绘参考的真实视觉识别与生成；连接核对 |
| 草稿变化却能沿用过期预览，重绘重复请求指纹缺少场景 | 指纹包含实际草稿或重绘文档、DPI 和相关输入 | 内容变化、重复提交和预览复用测试 |
| 重试变成矢量模式，丢失草稿、增强词和输出设置 | 保存经过允许字段筛选的输入快照，重试复用原输入；使用当前本机模型设置 | 断连后重试的 HTTP 测试；快照无服务地址和凭据断言 |
| 局部重绘没有提交当前对象的像素 | PNG 对象直接提交现有像素，矢量对象生成单对象视觉输入；缺少原上传图的导入文档仍可重绘 | 运输请求检查、真实单对象编辑与重试 |
| 对象的 evidence 携带整图要求，导致一个素材里重复多个细胞 | 插画使用单对象形态说明，原文证据留在科研溯源中 | 整图双主体描述隔离、重复细胞拒绝测试 |
| 植物、酵母、减数分裂或实验流程被动物分期快捷逻辑接管 | 快捷逻辑限于明确的通用分期；植物采用细胞壁和细胞板，特殊分裂方式明确使用通用草稿或相符素材细化 | 物种、实验、调控分子、跨领域用例及真实植物分裂图 |
| 被排除阶段反被当成必需项，否定激活仍出现正向箭头 | 单独记录排除项，核验明确否定句和不添加对象的要求；已确认科学矛盾保存草稿并报告失败 | 否定与排除测试、真实模型的 AKT 不连接案例 |
| 透明参考图变黑，识别产生重复 ID 或悬空端点 | 透明图合成白底；生成唯一 ID，丢弃无法确认的端点并提示；空的严格草稿识别不能被静默忽略 | 透明图、重复 ID、无效框与端点测试 |
| 第二次增强把上次 AI 文案当原文，延迟结果进入另一图版 | 始终保留作者原文，候选绑定图版和输入，改变后拒绝过期候选 | 实际控件处理函数和异步延迟测试 |
| 参考读取未完就能生成，切换图版时旧请求覆盖新图或丢编辑 | 参考未就绪时暂停生成；文档加载完成后整体切换，旧响应失效，保存后重新取最新修订 | 模拟延迟、切图和重新打开测试；实际界面保存与重开 |
| 失败、取消或部分完成后仍提示修改成功 | 界面使用真实终态；保留草稿并显示未完成，不宣称科学通过 | 失败状态测试、真实超时和随后成功重试 |
| AI 修改把内嵌 PNG 大段编码作为文字发出，锁定对象保护不足 | 文字规划只提交对象语义与素材摘要，锁定对象拒绝修改；图像核验仍使用图片 | 请求内容与锁定范围测试 |
| 手绘没有重启恢复，取消笔画或空文字影响撤销 | 本机暂存手绘、恢复像素和墨迹状态，迟到恢复不覆盖新笔画 | 草稿恢复与取消测试 |
| 较大合法草稿被 8000 字内部需求元数据限制拒绝，AI 文档不能重新导入 | 内部结构基线容量与场景上限对应，导入容量与生成文档匹配 | 120 对象草稿与文档容量验证 |

## 验证结果

- Python 完整回归：**483 passed、7 subtests passed**。本轮新增 33 个针对性用例；原生窗口脚本与普通测试分开运行。
- 前端：**18 个 JavaScript 回归脚本通过**，包含文档切换、重复增强、参考读取和手绘恢复。
- 真实模型结构案例：四步有丝分裂研究实验流程；EGF 激活 EGFR 且 AKT 不连接；五期植物细胞分裂；A 抑制 B、B 激活 C 且排除 D。逐项核对数量、身份与连接，本地检查均无错误。
- 真实上传参考：透明底的 EGFR/AKT 草稿，识别两个独立主体，保留观察位置，零连线没有被补成激活；结构预览直接复用。
- 真实插画：单个前期细胞具有连续核膜、核内凝集染色体、核外中心体，锁定作者备注不变。局部重绘首次超时，原图保留；按原输入重试后外轮廓改为深紫，另存修改版。备注、几何、关系与原版逐项不变，内部形态经前后看图核对。
- 实际界面：选中植物细胞、方向键移动、改字、撤销、重做、自动保存和重新打开，修改保留。

## 限制与后续使用

这些案例覆盖已定位的缺陷，不代表任意论文题材、物种和模型服务都已经正确。否定句检查只覆盖明确句式；复杂条件、罕见机制和模型返回的形态细节仍需作者审阅。视觉模型意见可能有误，状态保留为待核验。

AI 插画像素内部仍不是独立矢量对象。图像编辑服务不支持、断连或超时不能靠软件保证成功；软件的责任是明确状态、保住原对象和可用草稿，并提供可复用输入的重试。

本轮真实验证使用隔离数据，用户服务配置只读入内存；参考原图、私人任务、模型配置和密钥不进入公开源码与发行包。
