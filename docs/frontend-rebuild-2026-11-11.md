首页恢复直接可见的手绘草图、可编辑示意图/细节插画选择和结构预览；右栏恢复属性、检查、任务标签；侧栏保留素材和模板入口。更多菜单只承载低频参数、文件管理等操作。本段为当前行为；下面的初版默认可见表保留为设计迭代记录，已不代表当前全部呈现。

这次纠偏后重新运行全部前端测试 56 passed，资源与发布通道边界 6 passed；实际浏览器检查主要入口的可见性与打开行为。测试能证明功能仍可运行，易用性的进一步评价仍以真实使用反馈为依据。

## 用户要求与方向

用户反馈上一轮仍过于复杂，要求抛弃原有界面基础，按 Unslop 与组件规范重新设计。本轮取代上一轮默认呈现方式，不迁移科研对象引擎或更改保存协议。

- 产品：研究者将研究内容与已有科研图变成可直接编辑的图版。
- 性格：克制、清楚、直接。
- 视觉依据：纸张、绘图工具、论文图版；色彩集中在科研内容中。
- 内容重点：画布是编辑页的中心；输入与生成是首页中心。
- 连贯细节：图版名称和真实保存状态始终关联当前文件。

采用 BoardUI MIT 控件的原生 HTML/CSS/JavaScript 适配，继续使用 Unslop 的间距、颜色、图标、文案、字体、布局、细节、内容、动效九个检查维度。来源、具体版本与许可见 `THIRD_PARTY_UI.md`。没有复制付费 Pro 代码，没有引入 React 运行时。

## 新的操作结构

| 场景 | 默认可见 | 按需出现 |
| --- | --- | --- |
| 首页 | 描述、参考、优化、选项、生成 | 绘图方式、尺寸、示例、结构预览 |
| 其他起点 | 导入科研图、使用模板、空白绘图 | 文件选择后才显示转换与对照 |
| 导航 | 新建、查找操作、文档助手、项目和图版 | 搜索历史、分组、完整历史、设置 |
| 编辑 | 图版标题、保存、导出、浮动绘图工具 | 点选后显示右侧编辑区 |
| 属性 | 修改文字、字号、颜色、复制、删除、排列 | 科学状态、精确尺寸、路径工作区 |
| 图版菜单 | 图版设置、检查图版 | 文件与版本、排列与编辑、显示与吸附、工作区设置、检查与来源 |

属性栏由用户关闭，避免取消选择时自动收起造成反复跳动。极简模式首次打开图版默认不展开属性栏；专业模式通过图版菜单进入。连线工具自动显示含义选择，并保留明确取消操作。

## 架构落地

`canvas-studio.html` 的导航、图版栏、绘图工具、首页与创作选项结构重新组织；常用编辑控件直接属于属性栏，取消旧版从工具栏移动它们的步骤。原 DOM 操作目标保留，以免历史任务、快捷键、保存和模型入口断链。

`ui/styles/workspace.css` 重新编写。新版构建排除旧 `canvas-workbench.css`、`workspace-modes.css`、`workspace-shell.css`、`quick-edit-toolbar.css` 的整体布局；`ui/styles/feature-panels.css` 只保留所需的对话框、导出、项目等功能样式。旧文件留给旧入口和历史回归，不以覆盖它们的方式构造新版工作区。

原生菜单与输入控件统一焦点样式。绘图选项可通过 Esc 或点击外部关闭，内容保留；图版菜单关闭后恢复折叠。移除整页模式快照，沿用局部透明度与位移动效，尊重系统减少动态效果设置。

实机验收修复了：旧插入位置依赖导致启动中断、快捷编辑旧固定高度导致输入被裁切、标题区旧列布局、连线选项横向溢出，以及菜单继承的深色背景。启动加入可见的载入状态，避免尚未初始化时显示可点击的未就绪画布。
