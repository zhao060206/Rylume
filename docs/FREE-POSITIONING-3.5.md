# 自由连接与文字定位

## 调整已有箭头

1. 单击箭头，显示起点、终点和中间的圆形控制点。
2. 拖动起点或终点到对象边缘。绿色虚线框和圆点表示吸附位置，四条边和角落均可使用。
3. 松开鼠标完成。移动、缩放、旋转对象时，端点保留沿边的相对位置。中间圆点继续用于调整弯曲。

落在空白处不会断开原连接。按 Esc 可取消当前拖动。

## 绘制新连接

选择对象，点击「添加连线」，可从其边框的任意位置拖到另一个对象的边缘。也可依次点击两个对象，再拖动端点精调。

## 移动文字

直接按住对象名称或箭头旁的文字拖动，图形本身保持位置。文字边上显示绿色虚线选框时，方向键只微调文字，Shift 加大步长。双击文字或按 F2 改字。独立文本按住拖动即可移动。

Ctrl+Z 撤销，Ctrl+Y 重做。每次完整拖动为一步撤销。修改停止后自动保存，重新打开和 SVG / PDF / PNG / PPTX 导出保留位置。

专业属性中的「更多连线设置」可设置端点所在边及沿边位置百分比。上、下边从左到右计数，左、右边从上到下计数。「文字回到连线旁」恢复自动排版。
