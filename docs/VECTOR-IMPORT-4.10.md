# 科研位图转可编辑矢量：4.10

首页「导入已有图」选择 PNG/JPG/WebP，或 PDF 的一页。默认高保真模式在本机识别文字、描摹轮廓并修复测得的局部色阶差异。候选不包含位图；原文件保留，对照确认后才创建新图版。

## 99% 验收目标的含义

在原始像素分辨率渲染实际 SVG，将原图与输出中任一方非白的像素纳入比较。指标为 `100 × (1 − 前景 RGB 平均绝对误差 / 255)`。不以大片白底提高分数，不缩小到缩略图再验收，不将匹配百分比称为科学正确率。

只有该指标达到 99% 才允许将高保真候选作为正式图版打开，前后端均检查此条件。未达标、取消或失败保留原图；低清原图无法恢复已经丢失的细节。即使像素指标通过，也需要放大检查漏字、布局及科学含义。软件不保证任意输入无缺陷或所有机制关系都已识别。

轮廓描摹后，只修复实际像素差异所在的局部区域，输出为普通矢量路径。大于 35% 画面都需要修复的结果被拒绝，不用整幅像素网格掩盖描摹失败。

## 编辑与导出

- 点选已识别标签，在右侧改字。未改写标签保留原始字形轮廓，避免替换字体造成乱码和位置变化；改字、字号或颜色后切换为文字。未识别小字保留原始轮廓，并不宣称全部都已经 OCR 成文本。
- 「矢量细节」内可点选、多选、移动、改色和删除路径，支持局部撤销重做。输入位移后点击「移动所选路径」；颜色使用明确的应用按钮。取消时会提示尚未应用的修改。
- 「应用并保存」将此次修改作为主画布的一步操作；主画布可撤销。窗口内的未应用修改不会悄悄写入图版。
- 原图箭头保留为轮廓，不自动变成绑定科研对象的连接线；路径按绘制顺序分组，并不代表已经识别出每个分子的语义边界。
- SVG/PDF/PPTX 保留矢量，PNG 按物理尺寸和 DPI 导出。PPTX 中原字形为可编辑路径，已改写标签是文本框。不能将这两者统一宣传为所有标签都是可直接键入的文本框。
- 大图可能含数万条路径，PowerPoint 导出比普通模板慢；导出使用固定修订，不会被同时进行的编辑替换。
