# 4.4.1 更新入口验收

日期：2026-10-31。

素材库与模板库统一为同一管理器下的独立浮窗。拖动标题移动、右下角缩放、收起到底部名称入口、点击名称或原入口恢复；素材搜索与筛选 DOM 不重建，窗口位置、尺寸和滚动位置随窗口保留。素材按钮的展开状态跟随真实窗口状态。

实际浏览器核验素材库：标题拖动后位置从 (230,90) 到 (320,110)；右下角拖动后从 760×600 缩为 603×463；收起后用底部名称和原「添加素材」按钮分别恢复，尺寸位置及“受体”搜索词均保留。滚动位置 1499.33 在收起恢复后保持一致；素材与模板可同时收起并分别恢复。通过新页面插入单体膜受体、收起素材窗后画布保留 1 个可编辑对象，无控制台错误。

- 有新版时，左下角入口常驻；旧的“稍后提醒”不会隐藏入口。侧栏收起时保留图标和无障碍名称。
- 悬停或键盘聚焦展示目标版本日志，以纯文本显示；长内容可滚动，Esc 收起。
- 检查暂时失败、取消下载后保留已知新版；当前版本追上目标版本后隐藏入口。
- 重开软件会恢复已知新版的版本号和日志，并重新核对后端；离线不隐藏已知入口，升级后清除缓存。展示缓存不能授权下载或安装。
- 点击开始下载，下载过程显示进度；下载完成不会自行安装，需再次点击并先保存图版。

自动验证：573 项 Python 测试及 7 项子测试通过，原生窗口测试单独跳过；28 组 JavaScript 测试通过。新增行为测试覆盖悬停、键盘、版本比较、暂时失败、取消、进度、显式点击和不可信日志文本。

实际浏览器验收使用独立端口、独立空数据目录及模拟更新服务：确认左下角位置、键盘日志预览、长日志滚动、Esc、折叠导航、点击后出现 42% 模拟下载、取消后入口保留；无控制台错误。未调用真实下载、安装或重启接口。

本轮不升级用户安装的 4.4.0，不替换桌面快捷方式，不读取或改写个人模型配置。发布包在独立目录构建；真实联网下载与安装沿用此前签名验证、备用线路和保存后重启机制。
