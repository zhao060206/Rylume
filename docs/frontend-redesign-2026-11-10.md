# Rylume 前端重构记录

本文件记录第一轮。用户随后要求抛弃原信息架构重新设计，当前默认界面已由 [2026-11-11 重新设计记录](frontend-rebuild-2026-11-11.md) 取代；以下保留第一轮的实际实施与测试记录。

## 范围与方向

用户要求用提供的组件库清单和 GitHub 上的 Unslop 全面重构前端。本轮重建产品外围界面与交互，保留科研场景、SVG 画布引擎、保存协议和模型调用协议。

方向：帮助研究者把想法、资料和已有科研图变成可编辑图版；克制、精确、亲切；界面属于论文图版和绘图工具台。以中性灰与纸白承载操作，只在主操作、选中态中使用品牌绿；科研图、素材、真实模板承载内容颜色。图版和保存状态是贯穿界面的识别细节。

本轮直接实施的授权来自用户的“彻底的前端重构”及此前多次由开发者自行决定设计的要求。没有购买 Pro 组件，没有新增收费模型调用，没有替换本机安装，没有发布 GitHub Release。

## 评估结果

既有界面没有严重的霓虹和渐变装饰问题。主要问题是多轮界面调整导致的层叠与信息架构，而非缺少视觉特效：

- 桌面入口加载 19 个样式文件，基础层、产品层和重构层反复覆盖。
- 首页三块大入口与大输入区占据主要空间，主要操作与输出方式分离，真实科研图内容不明显。
- 窄窗口下工具名消失；关键功能分散在侧栏、工具栏和菜单之间。
- 新手只能通过图版名称双击重命名；没有统一的操作查找入口。
- 旧的快捷编辑浮层定位不适合右侧属性区，必须明确恢复为文档流中的稳定组件。
- 素材筛选占用大量纵向空间；固定两列不能利用宽窗口。
- 模式切换对整个页面做快照，会把大型 SVG 一起纳入动效。

全面改造来自用户明确要求，未把原界面误判为需要特效堆砌的营销页。

## 九轮落地

1. **间距**：4 px 基础节奏；侧栏 36 px 行，56 px 顶栏与工具区；分组内间距小于分组间距。
2. **配色**：统一纸白、中性灰和三个文本角色；主操作用品牌绿，画布、图形、插画配色不受界面主题影响。
3. **图标**：延续一致的线性 SVG 图标，去掉创作入口的星芒图标；工具栏在足够宽度下显示名字。
4. **文案**：首页明确“开始一张科研图版”，三条路径说明实际结果；删除泛化欢迎口号；提示描述优化会保留科学原意、核对后采用。
5. **文字**：统一系统中文字体、13–14 px 常规界面文本、12 px 次级信息、500 字重标题；字号和数字使用清晰层级。
6. **布局**：左侧项目与图版，中间画布，上方工具，右侧属性；首页生成方式与提交操作合并。文档助手延续独立右侧区域。1024 px 窗口下仍为属性栏保留宽度，避免遮盖画布。
7. **细节**：补齐命令搜索、菜单键盘导航、可见重命名入口、焦点状态、空搜索提示、图版命令的可用性判断；保留未完成的输入与已有功能。
8. **内容**：首页直接读取实际推荐模板及缩略图，不使用生成装饰图或虚构样板。素材库保留来源、收藏、双语名称、分类与模糊搜索。
9. **动效**：分段切换用局部位移，侧栏用短过渡；移除整页模式快照；尊重系统减少动态效果设置。

## 组件与技术选择

BoardUI MIT 版的按钮、输入与分段控件转换为适合现有工作台的原生实现，来源版本和许可证见 [THIRD_PARTY_UI.md](../THIRD_PARTY_UI.md)。没有声称加载 React 版运行时。

HeroUI Pro 和 beUI Pro 的公开页面用于设计比较，未复制付费代码。Bencho 的微交互和 Watermelon 的实际组件作为交互参考；Libraries.dev 的光球、发光边框不适合长期绘图工作区，因此没有加入。

新样式源：

- `ui/styles/components.css`：公共设计变量与基础控件。
- `ui/styles/workspace.css`：导航、首页、工具栏、画布外围和检查器。
- `ui/styles/panels.css`：浮窗、素材、模板、导入、文档、设置、更新和操作搜索。
- `ui/components/controls.js`：原生分段控件和菜单键盘行为。
- `ui/components/command-palette.js`：操作注册、查找、可用性与键盘操作。
- `ui/product-shell.js`：产品界面与现有功能模块之间的连接。

运行 `python scripts/build_ui.py` 更新唯一桌面样式入口 `ui/workbench-ui.css`。打包脚本与 spec 会拒绝过期的生成文件，安装后的软件无需 Node、CDN、远程字体或组件服务器。

既有绘图/功能样式保留在低优先级 `features` 层，新的组件、工作区和面板分别在明确的后续层。旧版 `/legacy` 页面保留原入口。本轮没有把已有画布编辑和科研对象代码移植到新框架。

## 验证

- 全部 Node 前端测试：55 passed，包括新增操作查找、图版命令边界、键盘切换和静态资源入口回归。
- 全部 Python 测试：643 passed、7 subtests passed；1 个原生窗口测试按项目约定跳过。
- 随后新增的 2 项样式构建与真实 HTTP 资源测试通过；与发布通道的 4 项回归合跑共 6 passed。
- 实际浏览器操作：输入跨起点切换保留；命令搜索空结果与键盘执行；打开素材库、搜索“线粒体”、切换名称语言；导入浮窗收起和恢复；改字、保存、重新打开；节点拖动、连线随动、撤销；极简/专业切换保留缩放和所选文字；四格式导出菜单。
- 实际保存通过本机 HTTP 场景接口重新读取，确认文字和修订持久化，而非只检查界面提示。
- 1024 × 768 和 1440 × 900 下无横向溢出；1440 px 时画布区域宽约 920 px。首页模板卡可打开实际对象、适用范围及编辑入口；首页搜索“导出”明确提示先打开图版。
- 论文参考图片沿用浏览器原生懒加载，详情图在打开时设置地址；此类外部参考内容仍需联网，新组件与界面资源不依赖外部 CDN。

宽窄屏、模板预览、设置和文档助手的最终验收截图与记录放在工作区 `outputs/Rylume-Frontend-2026-11-10`。生成模型的付费推理和新版 Windows 安装包本轮不在测试范围；未对未执行的部分声称验收。

下一次发布前应以当前代码生成安装包，按既有发布流程进行原生宿主与更新链验收；本次版本号继续保持已发布的 4.11.0。
