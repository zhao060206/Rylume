# 一套工作台，两种密度

右上角的「极简 / 专业」是同一软件的两种工作区布局，不是收费等级。两种模式使用同一份图版、素材、模型配置与导出能力。默认极简，并记住本机上次选择。

## 分区

顶部处理文件、新建、图版名称、工作区模式与导出。左侧负责添加内容与组织对象；中央只保留绘图工具和画布；右侧负责当前对象或画布的精细设置。

- 极简：保留模板、素材、AI 初稿，以及选择、连线、文字、撤销和批注。选中对象后直接改字和外观。精细属性、图层、检查和论文参考集中在「更多」，需要时仍可直接打开。
- 专业：显示「创作 / 组织」两组导航；默认打开图层和属性，检查直接可达。复制、删除和排列移到属性区，避免上下两套重复操作；关闭属性时回到画布快捷栏。

模板按钮直接打开模板库，移除中间的一层启动面板。图版配色移入画布设置。合并视图菜单中重复的属性、检查、排版建议入口，以及重复的快捷键入口；原有命令保持兼容。

## 统一样式

统一使用白色工具面、浅灰画布、深灰文字和低饱和绿色选中态。导航、素材、属性、批注、检查、导出与设置共用边框、间距、字号、圆角与控件高度。界面主题不修改图中的科学配色或字号。

## 切换

模式切换保留图版内容、当前修订、选中对象、缩放和视口中心。每种模式保留本次会话中的面板布局；较窄窗口避免同时叠放两个抽屉。首次打开图版适合窗口；切换模式不会重新适合。

支持 View Transitions 的 WebView2 使用约 420 ms 的布局过渡，侧栏淡入、位置平滑变化；较旧引擎使用轻量淡入过渡。快速来回点击按最终选择落定。系统启用「减少动态效果」时关闭这些过渡。模式按钮可用 Tab、Enter、空格与左右方向键操作。

切换时会保存正在输入的文字，仍可撤销。批注面板保持打开，批注草稿保留；关闭面板后再按当前模式恢复布局。

实现：`ui/workspace-modes.js` 管理模式、布局和切换；`ui/workspace-modes.css` 定义统一样式和动效；`ui/panel-layout.js` 对嵌套分区调整只计算一次视口偏移。没有引入新框架或收费服务。
