理象 · Rylume 3.5.0

1. 解压整个压缩包，双击 Rylume.exe 或“启动理象.cmd”。请保留 _internal 文件夹。
2. 支持 Windows 10/11 x64。需要 Microsoft Edge WebView2 Runtime。
3. 模板、素材和直接编辑无需 API key；AI 功能请在模型设置中填写你自己的服务。
4. 本机数据默认保存在 %LOCALAPPDATA%\CellFigureStudio。
5. 此发行包不包含开发者的密钥、配置、历史任务或日志。
6. 更新时退出旧程序，再解压到新文件夹。请勿覆盖或上传自己的数据目录。

源码、更新与问题反馈：https://github.com/zhao060206/Rylume
版本下载：https://github.com/zhao060206/Rylume/releases
许可：AGPL-3.0-only。第三方插画请按附带署名使用。

「设置 → 资源与更新」可下载其他学科素材、模板和新版程序。当前图版保存后再重启更新，失败会恢复旧版。

第一次使用：
1. 点首页「先试着改一张图」，无需配置 AI 即可开始。
2. 也可点「自己画一张」，点击素材后拖动、改字、连线。
3. 误操作点「撤销」；改字时可点「完成」或「取消」。
4. 点「导出图片」，按论文图片、可编辑 PPT 等用途保存。

右上角「极简 / 专业」切换同一图版的工作区布局；两种模式功能相同。极简的精细设置、图层、检查和参考集中在「更多」。切换保留选区、缩放和修改，系统减少动态效果设置会关闭过渡。
