理象 · Rylume 3.0.0

1. 解压整个压缩包，双击 Rylume.exe 或“启动理象.cmd”。请保留 _internal 文件夹。
2. 支持 Windows 10/11 x64。需要 Microsoft Edge WebView2 Runtime。
3. 模板、素材和直接编辑无需 API key；AI 功能请在模型设置中填写你自己的服务。
4. 本机数据默认保存在 %LOCALAPPDATA%\CellFigureStudio。
5. 此发行包不包含开发者的密钥、配置、历史任务或日志。
6. 更新时退出旧程序，再解压到新文件夹。请勿覆盖或上传自己的数据目录。
